2. 全文摘要

NVIDIA 为其最强工作站 DGX Station 推出了 Agent Toolkit 软件工具包，开发者仅需三步、约 30 分钟即可在本地部署并运行 AI 智能体。该工具包整合了 NemoClaw 智能体框架、Nemotron 3 Ultra（5500 亿参数开源模型）和 Omniverse 仿真平台，配合 OpenShell 安全运行时实现沙箱化管理。DGX Station 搭载 GB300 Blackwell Ultra GPU，提供最高 20 petaflops 的 FP4 算力和 748GB 一致性内存，使得团队可以在桌面端运行大模型而无需支付云端 token 费用。NVIDIA 同时宣布与 Adobe、Blender、Epic Games 等合作伙伴推进 MCP 协议集成，进一步扩展了从硬件到中间件再到应用层的全栈 AI 工作站生态。

3. 英文原文

[1] NVIDIA has enabled DGX Station users to run personal AI agents locally through its NVIDIA Agent Toolkit, which can be set up in just three steps.

[2] Agentic AI has brought new kinds of use cases for PCs, especially powerful ones such as NVIDIA’s DGX Station, which packs the GB300 “Blackwell Ultra” GPU. To make full use of its power, NVIDIA is offering its Agent Toolkit software, which unleashes these capabilities in just 30 minutes — the time it takes to set up the software.

[3] The NVIDIA Agent Toolkit is a complete software stack that brings NVIDIA NemoClaw, Nemotron 3 Ultra, and Omniverse together. With NVIDIA Omniverse libraries, agents can access tools and skills in a secure runtime locally without needing to connect to the internet.

[4] Developers can also connect multiple systems to serve concurrent users, more agents, and bigger model sizes. Key components include:

  • NVIDIA NemoClaw: open blueprints for building custom autonomous agents, packaging the model, harness, and runtime together.
  • NVIDIA Nemotron 3 Ultra: a frontier 550-billion-parameter open model, optimized to run on DGX Station GB300 systems.
  • NVIDIA Omniverse libraries: extend agent skills into physics simulation and 3D asset workflows.
  • NVIDIA OpenShell: the open-source secure runtime, keeps agents sandboxed and governed according to defined policies.
  • NVIDIA GB300 Grace Blackwell Ultra Desktop Superchip: delivers up to 20 petaflops of FP4 AI compute and 748GB of coherent memory.
  • NVIDIA ConnectX-8 SuperNIC: delivers up to 800GB/s of bandwidth, supporting linking up to two DGX Stations.

[5] With the Nemotron 3 Ultra open model, teams running agents at scale can utilize the hardware’s leading-edge performance without worrying about token cost, since the hardware purchase is the only thing they will be paying for.

[6] NVIDIA has also announced a blueprint for integrating Omniverse into libraries, enabling developers to prepare 3D scenes for Physical AI workflows through NemoClaw’s “RTX Sensor Simulation.” Teams running OpenClaw can now make use of Nemotron 3 Ultra and Omniverse tools for local inferencing on DGX Station.

[7] NVIDIA is working with partners such as Adobe, Blender, Unreal Engine, Epic Games, SideFX, Foundry, and Canva to integrate MCP (Model Context Protocol) connections, allowing AI agents to work inside the tools where scenes, shots, timelines, assets, and edits are being rendered.

[8] The DGX Station is available for order through ASUS, Dell, Exxact, Gigabyte, HP, MSI, and Supermicro, marking a significant step toward making on-premises AI agent deployment accessible at the desktop level.
