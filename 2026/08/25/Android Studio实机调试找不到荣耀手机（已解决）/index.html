Android Studio实机调试找不到荣耀手机（已解决）

踩坑记录 ADB Android Studio 真机调试 荣耀手机 2026/08/25

首先排查：

是否打开开发者模式

操作步骤：

开发人员选项-调试-无线调试开启

Android Studio打开Device Manager（找不到请双击Shift键搜索）

Physical-Pair Using WiFi

使用自己手机无线调试页面下的使用二维码配对设备扫描AS提供的二维码

等待（笔者等待五分钟左右才连上，请确保连接同一个LAN）
